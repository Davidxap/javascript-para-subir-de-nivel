# JavaScript para Subir de Nivel

> Un libro técnico, práctico y en español para pasar de "sé usar JavaScript" a entender de verdad cómo funciona.
> **Autor: David Arturo Arroyave Pérez** (Manizales, Colombia)

## Sobre este libro

Este libro nació de mis propias notas de estudio: funciones modernas, prototipos, asincronía, patrones, seguridad y las APIs más recientes del lenguaje (ES2025–ES2026). La promesa: **de usarlo a entenderlo** — de la sintaxis a los mecanismos internos.

Empieza por la [Introducción](introduccion) (por qué un libro y no otro video).

## Cómo aprovecharlo

1. **Lee con el editor abierto.** Cada ejemplo tiene botón Run: ejecútalo, rómpelo, mira qué pasa.
2. **Resuelve antes de mirar.** Las pistas y las soluciones vienen ocultas a propósito: abre "Ver pistas" solo si te atascas y "Ver solución" solo después de intentarlo.
3. **Vuelve sobre lo leído.** El segundo paso por un capítulo es donde se fija el conocimiento.
4. **Explícalo.** Si no puedes explicarlo con tus palabras, todavía no es tuyo.
