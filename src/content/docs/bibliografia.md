# Bibliografía y fuentes

Materiales que sustentan este libro. Recomendados para profundizar después de cada capítulo.

## Documentación canónica

- **MDN Web Docs** — Referencia del lenguaje y de las APIs web. <https://developer.mozilla.org/es/docs/Web/JavaScript>
- **ECMA-262 (Especificación ECMAScript)** — El estándar formal del lenguaje. <https://tc39.es/ecma262/>
- **Propuestas TC39** — El proceso y las propuestas que llegan a ES20XX. <https://github.com/tc39/proposals>

## Libros y guías

- **Eloquent JavaScript** — Marijn Haverbeke. <https://eloquentjavascript.net/>
- **You Don't Know JS (2ª ed.)** — Kyle Simpson. <https://github.com/getify/You-Dont-Know-JS>
- **The Modern JavaScript Tutorial** — javascript.info. <https://javascript.info/>

## Lecturas complementarias

- Documentación de V8 (optimización y motores JS). <https://v8.dev/>
- Open Web Application Security Project (OWASP). <https://owasp.org/>
