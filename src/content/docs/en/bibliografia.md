# Bibliography and sources

Materials that support this book. Recommended for further reading after each chapter.

## Canonical documentation

- **MDN Web Docs** — Reference for the language and web APIs. <https://developer.mozilla.org/es/docs/Web/JavaScript>
- **ECMA-262 (ECMAScript Specification)** — The formal standard of the language. <https://tc39.es/ecma262/>
- **TC39 Proposals** — The process and proposals that make it into ES20XX. <https://github.com/tc39/proposals>

## Books and guides

- **Eloquent JavaScript** — Marijn Haverbeke. <https://eloquentjavascript.net/>
- **You Don't Know JS (2nd ed.)** — Kyle Simpson. <https://github.com/getify/You-Dont-Know-JS>
- **The Modern JavaScript Tutorial** — javascript.info. <https://javascript.info/>

## Further reading

- V8 documentation (optimization and JS engines). <https://v8.dev/>
- Open Web Application Security Project (OWASP). <https://owasp.org/>
