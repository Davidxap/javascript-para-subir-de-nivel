# JavaScript to Level Up

> A technical, practical book in Spanish to go from "I know how to use JavaScript" to truly understanding how it works.
> **Author: David Arturo Arroyave Pérez** (Manizales, Colombia)

## About this book

This book was born from my own study notes: modern functions, prototypes, asynchrony, patterns, security, and the language's latest APIs (ES2025–ES2026). The promise: **from using it to understanding it** — from syntax to internal mechanisms.

Start with the [Introduction](introduccion) (why a book and not another video).

## How to get the most out of it

1. **Read with your editor open.** Every example has a Run button: run it, break it, watch what happens.
2. **Try before you look.** Hints and solutions are collapsed on purpose: open "Show hints" only if you're stuck, and "Show solution" only after you've tried it yourself.
3. **Read it twice.** A second pass over a chapter is where the knowledge sticks.
4. **Explain it back.** If you can't explain a concept in your own words, it isn't yours yet.
