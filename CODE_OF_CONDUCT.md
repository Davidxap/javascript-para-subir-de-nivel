# Código de conducta

Sé respetuoso y constructivo. No se aceptan acoso, ataques personales ni discriminación en issues, pull requests o discusiones.

Este proyecto sigue el espíritu del [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/). Reportá problemas en privado al mantenedor por GitHub.
